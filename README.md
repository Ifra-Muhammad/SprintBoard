SprintBoard — Interactive Kanban Project Dashboard

SprintBoard is a simple and interactive Kanban project management dashboard designed to help teams organize, manage, and track their tasks efficiently.

The dashboard organizes tasks into three categories: To Do, In Progress, and Done, making it easier to monitor project progress.

Project Goals

Organize tasks across three workflow columns.

Create, edit, and delete tasks.

Track task priorities and due dates.

Search and filter tasks.

Move tasks between different statuses.

Save tasks using browser LocalStorage.

Display task statistics and completion progress.
