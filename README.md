# SprintBoard – Project Management Dashboard

SprintBoard is a responsive task management dashboard built using HTML, CSS, and JavaScript. It helps users organize daily tasks, manage priorities, track progress, and monitor task completion through a Kanban board.

## Features

- **Task Management:** Create, edit, and delete tasks.
- **Kanban Board:** Organize tasks into To Do, In Progress, and Done columns.
- **Drag and Drop:** Move tasks between columns using drag and drop.
- **Alternative Task Movement:** Change task status using the status dropdown.
- **Search Tasks:** Search tasks by title or description.
- **Priority Filter:** Filter tasks by High, Medium, and Low priority.
- **Local Storage:** Save tasks in the browser so they remain available after refreshing the page.
- **Dashboard Statistics:** View total tasks, pending tasks, in-progress tasks, and completed tasks.
- **Completion Percentage:** Track overall task completion.
- **Responsive Design:** Adapted for desktop, tablet, and mobile screens.
- **Accessibility:** Includes form labels, keyboard navigation, visible focus states, and accessible modal controls.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage



## Getting Started

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.
5. Start creating and managing your tasks.

No additional packages or installations are required.

## How to Use

1. Click **Add Task** to create a new task.
2. Enter the task title, description, priority, due date, and status.
3. Click **Save Task**.
4. Use the Edit and Delete buttons to manage existing tasks.
5. Move tasks between columns using drag and drop or the status dropdown.
6. Use the search bar and priority filter to find specific tasks.
7. Check the dashboard statistics to monitor your progress.

## Testing

The following features were tested:

- Creating, editing, and deleting tasks.
- Required field validation.
- Drag-and-drop functionality.
- Moving tasks using the status dropdown.
- Searching tasks by title and description.
- Filtering tasks by priority and resetting filters.
- Saving tasks after page refresh.
- Updating dashboard statistics and completion percentage.
- Empty board and long task title handling.
- Keyboard navigation and modal controls.
- Responsive layout on smaller screens.

## Limitations

- Task data is stored in browser Local Storage.
- Tasks are not synchronized across different browsers or devices.
- The project does not currently include user authentication or a backend database.
- The dashboard uses sample tasks for initial demonstration.
